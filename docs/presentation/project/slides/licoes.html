COQUÍ · firmware para o M-VAVE FM-1

Cinco coisas. Um fork com testes deixa você mudar muito sem medo. Testar fora do aparelho foi o que permitiu ir rápido: o FM-1 só entrou no fim, para confirmar. Medir antes evitou desenhar um reverb que não cabia. Escrever ritmos como texto fez o código ser revisável por quem entende de música, não só por quem entende de C. E, mesmo assim, o aparelho ainda trouxe surpresas de ambiente: MIDI no WSL, versão do Python. Vale tratar o setup de teste como parte do projeto.
