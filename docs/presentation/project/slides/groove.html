A mesma grade, na tela do FM-1

COQUÍ · firmware para o M-VAVE FM-1

A decisão de que os ritmos seriam strings foi uma das melhores do projeto. Dá para ler o padrão no código como uma partitura, revisar num diff, e testar automaticamente: o teste confere o tamanho de cada linha, os caracteres válidos, toca 8 compassos de cada estilo e mede o pico da mistura. Foi esse teste que mostrou que a salsa e o mambo estouravam o fundo de escala quando vários tambores caíam no mesmo passo. A mesma string alimenta a tela do FM-1 e a página do hub.
