A pixel art é código: sprites em strings no C, desenhados num canvas de 240×240. A mesma cena foi portada para JavaScript no hub, e este deck usa as mesmas cores.

COQUÍ · firmware para o M-VAVE FM-1

A identidade visual nasceu na tela de 240 por 240 do aparelho e foi para o resto: a paleta do firmware é a do site, do editor e deste deck. Não existe um arquivo de imagem na tela do FM-1: a lua, a palmeira, os vaga-lumes (cucubanos, os de Porto Rico) e o sapinho são desenhados por código, retângulo por retângulo, e animados redesenhando só o que mudou, porque mandar a tela inteira pelo barramento custa 115 KB. As quatro cores de destaque (ROSA, MANGO, MAR, LIMA) são escolhas do usuário no menu SYSTEM.
