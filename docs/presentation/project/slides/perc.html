COQUÍ · firmware para o M-VAVE FM-1

A primeira decisão grande: samples ou síntese? A flash tem espaço para uns 26 segundos de áudio no total, então a percussão inteira é sintetizada, só com inteiros. Cada instrumento é uma linha numa tabela: afinação, parcial, decaimentos, filtro. Os valores foram calculados num computador e colados no código como números, porque o chip não faz float. O teste mediu cada tecla: no começo vários sons passavam do fundo de escala em até 3,5 dB; cada instrumento ganhou um ganho próprio para ficar entre -6 e -16 dB.
