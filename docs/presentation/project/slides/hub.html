HUB · EMULADOR · EDITOR

O mesmo código C roda no FM-1, no navegador e no CI

Hub (GitHub Pages)

Os áudios são gravados do próprio firmware em modo host e virados MP3 por um script.

Emulador (WebAssembly)

O firmware compilado com Emscripten; o teste confere som e telas iguais ao host, amostra por amostra.

Editor (Web MIDI)

Edita os sons ao vivo no aparelho por SysEx, com o GROOVE dos sons PERC.

COQUÍ · saulofilho.github.io/coqui-fm1

O firmware é um arquivo C que compila de três jeitos: para o chip, para o computador (o modo host, que gera WAV e imagens das telas) e para o navegador. Isso é o que torna o projeto testável sem o aparelho. O hub usa isso duas vezes: os áudios de cada estilo são gravados do firmware de verdade, e o emulador é o próprio firmware em WebAssembly. Quem abre o site ouve exatamente o que o FM-1 toca. Link: saulofilho.github.io/coqui-fm1.
