COQUÍ · firmware para o M-VAVE FM-1

Os desafios foram quase todos de restrição, não de algoritmo. O primeiro build para o chip falhou no link: uma divisão de 64 bits escondida numa função herdada, inlined no código novo. A memória cheia mudou o desenho do AMBIENTE. A falta de vozes mudou o desenho do PERC. E alguns só apareceriam no aparelho: as ferramentas de CPU e de samples recusavam qualquer firmware que não fosse o GR!MM; pegamos isso lendo o código antes do teste. O último foi de ambiente: o python-rtmidi não tem pacote pronto para o Python mais novo no Windows.
