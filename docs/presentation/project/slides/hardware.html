Para quem vem de web ou backend: aqui não tem sistema operacional, não tem float, não tem malloc para nada que importa. O áudio roda numa interrupção que tem 5,8 milissegundos para entregar 256 amostras; se atrasar, você ouve um estalo. Uma divisão de 64 bits não compila: o link falha porque a biblioteca não existe. Essas restrições moldaram todas as decisões que vêm a seguir.
