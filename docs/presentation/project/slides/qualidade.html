COQUÍ · firmware para o M-VAVE FM-1

A regra foi: nada vai para o aparelho sem passar no host. O modo host gera o áudio e as telas do firmware no computador, e os testes comparam com referências gravadas. Quando a mudança de som era intencional, a referência foi refeita de propósito, nunca para fazer o teste passar. O teste de estresse com sanitizers achou um estouro de buffer real. E o teste web garante que o emulador do site é o mesmo firmware, amostra por amostra. O release no GitHub roda tudo de novo e assina o pacote.
